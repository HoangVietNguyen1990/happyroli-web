# 🥐 HappyRoli.com.au — Standalone Bakery Roster & Payroll Hub

Standalone, ultra-lightweight Python + SQLite + Modern Web UI application built for **Brumby's Bakery Pakenham** (`happyroli.com.au` / Kamatera Cloud `103.125.218.205`).

## 🚀 Quick Deploy on Kamatera Ubuntu Server (`103.125.218.205`)

```bash
git clone https://github.com/HoangVietNguyen1990/happyroli-web.git /opt/happyroli_web
cd /opt/happyroli_web
chmod +x deploy_kamatera.sh
sudo ./deploy_kamatera.sh
```
